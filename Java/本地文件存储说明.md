# 本地文件存储配置说明

## 一、功能说明

本方案使用本地文件系统存储图片，无需云存储服务，适合开发阶段或小型项目。

### 工作流程：
1. **前端上传图片** → 调用后端上传接口 → 后端保存到本地 `uploads/` 目录 → 返回完整 URL
2. **前端显示图片** → 直接使用后端返回的完整 URL 访问图片（如 `http://localhost:8080/uploads/menu/xxx.jpg`）

## 二、配置说明

### 1. 配置文件（`application.yml`）

已添加以下配置：

```yaml
file:
  upload:
    # 文件存储根目录（相对于项目根目录）
    base-path: uploads/
    # 图片访问路径前缀（用于返回给前端）
    access-path: /uploads/
    # 允许的文件类型
    allowed-types: image/jpeg,image/jpg,image/png,image/gif,image/webp
    # 最大文件大小（字节），默认 5MB
    max-size: 5242880
```

### 2. 目录结构

上传的文件会按以下结构存储：

```
项目根目录/
  └── uploads/
      └── menu/              # 路径前缀（如果指定）
          └── 2024/         # 年份
              └── 01/       # 月份
                  └── 15/   # 日期
                      └── abc123.jpg  # 文件名（UUID + 扩展名）
```

### 3. 文件访问

上传成功后，后端会返回完整的访问 URL：
- **完整 URL**：`http://localhost:8080/uploads/menu/2024/01/15/abc123.jpg`
- **相对路径**：`/uploads/menu/2024/01/15/abc123.jpg`

前端可以直接使用完整 URL 显示图片，无需额外处理。

## 三、使用示例

### 前端上传图片：

```javascript
import { uploadFile } from '@/api/files'

// 选择图片
uni.chooseImage({
  count: 1,
  success: async (res) => {
    const filePath = res.tempFilePaths[0]
    try {
      const result = await uploadFile(filePath, 'menu/')
      console.log('上传成功，图片URL:', result.url)
      // result.url: http://localhost:8080/uploads/menu/2024/01/15/xxx.jpg
      // 将 result.url 保存到菜单的 image 字段
    } catch (error) {
      console.error('上传失败:', error)
    }
  }
})
```

### 前端显示图片：

```vue
<template>
  <image :src="menu.image" mode="aspectFill" />
</template>
```

后端返回的 `menu.image` 字段就是完整的 URL，直接使用即可。

## 四、注意事项

### 1. 目录权限
- 确保 `uploads/` 目录有写入权限
- 如果目录不存在，程序会自动创建

### 2. 生产环境
- **开发环境**：使用相对路径 `uploads/`，文件存储在项目根目录
- **生产环境**：建议使用绝对路径，如 `D:/uploads/` 或 `/var/uploads/`

修改 `application.yml` 中的 `base-path` 配置：

```yaml
file:
  upload:
    base-path: D:/uploads/  # Windows 绝对路径
    # 或
    base-path: /var/uploads/  # Linux 绝对路径
```

### 3. 文件清理
- 建议定期清理旧文件，避免占用过多磁盘空间
- 可以编写定时任务，删除超过一定时间的文件

### 4. 跨域问题
- 如果前端和后端不在同一域名，需要配置 CORS
- 已在 `SecurityConfig.java` 中配置了 CORS，支持常见的前端开发端口

### 5. 文件大小限制
- 默认最大文件大小为 5MB
- 可以在 `application.yml` 中修改 `max-size` 配置

### 6. 文件类型限制
- 默认只允许图片类型（jpg, jpeg, png, gif, webp）
- 可以在 `application.yml` 中修改 `allowed-types` 配置

## 五、与云存储对比

| 特性 | 本地存储 | 云存储（OSS） |
|------|---------|--------------|
| **成本** | 免费 | 按使用量计费 |
| **配置复杂度** | 简单 | 需要配置 AccessKey |
| **扩展性** | 受服务器磁盘限制 | 几乎无限扩展 |
| **访问速度** | 取决于服务器带宽 | 通常更快（CDN） |
| **适用场景** | 开发/小型项目 | 生产/大型项目 |

## 六、迁移到云存储

如果后续需要迁移到云存储（如阿里云 OSS），只需要：
1. 实现 `FileStorageService` 接口的云存储版本
2. 替换 `FileStorageServiceImpl` 为云存储实现
3. 修改配置文件，添加云存储相关配置

接口设计已考虑了可扩展性，迁移成本很低。
